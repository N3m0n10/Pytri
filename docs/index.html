▦ Matrices

Incidence matrix follows PETRI.incidence_matrix: rows are States and columns are arcs. Positive values leave a State toward an Action; negative values enter a State from an Action. The Marking vector is the current ficha_count of each State.

❓ Help & Shortcuts

◯

Create elements

Use the toolbar to add places, transitions and arcs. Click on the canvas to place an element.

↗

Connect elements

Choose Add Arc, then click a source element and a target element. Configure the arc type and weight in the inspector.

✎

Edit

Select an element to move, rename, rotate or delete it. Drag labels independently to reposition them.

▦

Matrices

The incidence matrix describes the relation between places and arcs. The marking vector shows the current number of tokens in each place.

⇩

Save / Load

Your current net is saved automatically in the browser. Use Export / Import JSON to move a net between browsers or devices.

📱
